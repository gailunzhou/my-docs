# C-数据结构

## 1. 基本概念

*   数据结构：是相互之间存在一种或多种特定关系的数据元素的集合。
*   数据：描述客观事物的符号，是计算机中可操作的对象，是能被计算机识别，并输入给计算机处理的符号集合。
*   **数据元素：是数据的基本单位，例如，一个学生的整体信息（学号，姓名，性别，年龄，班级）就是一个数据元素**
*   **数据项：一个数据元素由若干个数据项组成，数据项是数据不可分割的最小单位**
*   数据对象：是性质相同的数据元素的集合，是数据的一个子集
*   容器：装入数据元素的外部对象，一般是先有数据关系再有可以装入数据元素的容器
*   结点：数据关系中，用于建立关系支撑的连接点
*   迭代器：可以遍历集合的对象，为各种容器提供了公共的操作接口
*   **前驱节点：数据值小于节点n，且与节点n数值最接近的节点 (记为节点m)**
*   **后继节点：数据值大于节点n ，且与节点n数值最接近的节点（记为节点m）**

## 2. 数据结构分类

数据结构分类主要为逻辑结构和物理结构

### 2.1 逻辑结构

#### 2.1.1 集合

*   集合结构中数据元素除了属于同一种类型以外，别无其他关系

#### 2.1.2 线性结构

*   线性结构中的数据元素之间存在一对一的关系

#### 2.1.3 树型结构

*   结构中的数据元素之间存在一对多的关系

#### 2.1.4 网状结构

*   结构中的数据元素之间存在多对多的关系

**可以按照以下方式进行分类：**

*   **线性结构：（一对一）**

    *   **数组**
    *   **栈**
    *   **链表**
    *   **队列**
*   **非线性结构：（一对多或多对多）**

    *   **哈希表**
    *   **树**
    *   **堆**
    *   **图**

### 2.2 物理结构

数据的逻辑结构在计算机中的存储形式被称为数据的逻辑结构

#### 2.2.1 顺序存储结构

把逻辑上相邻的结点存储在物理位置上相邻的存储单元里，例如数组

#### 2.2.2 链接存储结构

逻辑上相邻的结点可以存储在物理位置不相邻的存储单元中，例如链表

#### 2.2.3 数据索引存储结构

#### 2.2.4 数据散列存储结构 hash

## 3. 实例

一个结构体作为数据元素，里面有两个数据项，分别是指针数组和数组实际元素个数

```c
#define MAX_ARRAY_SIZE	100

typedef struct
{
	//指针数组
	void *Data[MAX_ARRAY_SIZE];
	//指针中数据元素个数
	int size;	
}array;
```

使用内存分配的方式创建一个结构体

```c
#include <stdlib.h>

//创建好后返回结构体的地址，因此类型是 array *
array *create_array(void)
{
	array *new_array = (array *)calloc(1 ,sizeof(array));
	if(new_array == NULL)
	{
		printf("创建失败：内存分配失败\n");
		return NULL;
	}
	(*new_array).size = 0;//元素个数为0

	printf("已创建\n");
	return new_array;
}
```

使用完需要释放结构体的内存

```c
void free_array(array *array_add)
{
	free(array_ad);
	array_ad = NULL;
	printf("已释放\n");
}
```

判断结构体中数组是否为空

```c
#include <stdbool.h>

bool array_isempty(array *array_ad)
{
	if(array_ad -> size == 0)
	{
		return true;
	}
	return false;
}
```

判断结构体中数组是否为满

```c
#include <stdbool.h>

bool array_isfull(array *array_ad)
{
	if(array_ad -> size == MAX_ARRAY_SIZE)
	{
		return true;
	}
	return false;
}
```

在已有数据范围内指定位置插入数据

```c
void insert_data(array *array_ad ,int index ,void *data_ad)
{
	//先判断是否已满
	if(array_isfull(array_ad))
	{
		printf("数组已满，无法添加\n");
		return ;
	}
	//判断指定的位置是否可行
	if(index < 0 || index > array_ad->size)
	{
		printf("索引超出范围\n");
	}
	for(size_t i = array_ad->size ; i > index ;i--)
	{
		array_ad->Data[i] = array_ad->Data[i - 1];
	}
	//从第max+1项开始一直到index前一项，从第max+1项开始是因为可以直接尾插，用前一项覆盖后一项实现移动
	array_ad->Data[index] = data_ad;
	array_ad->size ++;
	printf("添加成功\n");
}
```

删除指定位置的数据

```c
void delete_data(array *array_ad ,int index)
{
	//判断是否为空
	if(array_isempty(array_ad))
	{
		printf("数组为空，无法删除数据\n");
		return ;
	}
	//判断指定的位置是否可行
	if(index < 0 || index >= array_ad->size)
	{
		printf("索引超出范围\n");
		return ;
	}
	for(size_t i = index ; i < array_ad->size - 1 ; i++)
	{
		array_ad->Data[i] = array_ad->Data[i+1];
	}
	array_ad->Data[array_ad->size - 1] = NULL;
	array_ad->size --;
	printf("删除成功\n");
}
```
