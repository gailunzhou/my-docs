# C语法基础

## 1. static关键字

### 1.1 作用于函数

定义函数时前面加上static关键字可以让函数仅在当前文件内作用，其他文件无法调用

例子

```c
#include <stdio.h>

//函数声明
static int add(int num1 ,int num2);

int main(int argc, char const *argv[])
{
    printf("%d \n" ,add(1 ,2));//3
    return 0;
}

static int add(int num1 ,int num2)
{
    return num1+num2;
}

```

### 1.2 作用于变量

当在定义变量时加上该关键字后，变量的存储地方就从栈变到了内存，假设是一个函数的局部变量，如果**加上了static关键字后每次调用函数不会重新初始化该变量，而是直接从内存中获取值**

## 2. 递归函数

递归函数是**函数内部会调用自身**，函数会从最开始的第一层开始内部调用第二层函数...到第N层函数，因此**上层函数会等待下层函数结束并返回，上层函数才会拿到下层的返回值进行后续代码直到结束并返回最终值**

注意：

**递归函数会有造成内存溢出的风险，不允许滥用**

因为递归函数在递归过程中，cpu并不知道要调用多少次，而每一次调用都会在栈区里开辟一块该函数的空间（栈帧），而上层函数的空间又一直没有释放，很容易造成内存溢出

使用例子

```c
#include <stdio.h>
#include <stdlib.h>

int factorial(int num1);

int main(int argc, char const *argv[])
{
    
    printf("5的阶乘是%d \n" ,factorial(5));//120

    return 0;
}

int factorial(int num1)
{
    if (num1 < 0)
    {
        printf("负数无阶乘，程序退出\n");
        exit(1);
    }
    else if (num1 == 0)
    {
        return 1;
    }
    else
    {
        return factorial(num1 -1)*num1;
    }
    
}

```

## 3. 函数指针

一个指向函数地址的指针

语法：

```c
return_type (*function_pointer)(parameter_list);
```

注意：

**由于函数指针可以指向多个函数的地址，所以这些函数的返回值类型必须都是相同的**

通过函数指针可以直接调用函数，适用于接口的场景和回调函数中

简单使用例子

```c
#include <stdio.h>

double add(int num1 ,int num2);

double sub(int num1 ,int num2);

int main(int argc, char const *argv[])
{
    int n1 ,n2;
    printf("请输入两个正整数，用空格隔开\n");
    scanf("%d %d" ,&n1 ,&n2);

    //函数指针
    double (*funcp)(int a ,int b);

    //将具体函数的地址交给指针以实现调用
    funcp = add;
    printf("funcp调用add函数的结果为 %.2f \n" ,funcp(n1 ,n2));

    //通过不同的函数地址，以实现不同函数的调用
    funcp = sub;
    printf("funcp调用sub函数的结果为 %.2f \n" ,funcp(n1 ,n2));

    return 0;
}

double add(int num1 ,int num2)
{
    double res = (double)num1 + num2;
    return res;
}

double sub(int num1 ,int num2)
{
    double res = (double)num1 - num2;
    return res;
}

```

## 4. 指针函数

一个返回值是指针的函数

```c
return_type *function_name (parameter_list);
```

使用注意：

**不能用于返回函数内部局部变量地址，因为局部变量会随函数调用结束一起释放**

简单使用例：

```c
#include <stdio.h>

int *add(int num1 ,int num2);

int res;

int main(int argc, char const *argv[])
{
    int n1 ,n2;
    printf("请输入两个正整数，用空格隔开\n");
    scanf("%d %d" ,&n1 ,&n2);

    //因为返回的是一个指针，因此要用另一个指针来存储
    int *thisres = add(n1 ,n2);
    printf("调用 *add 后结果为：%d \n" ,*thisres);

	//也可以
	printf("调用 *add 后结果为：%d \n" ,*add(n1 ,n2));

    return 0;
}

int *add(int num1 ,int num2)
{
    res = num1 + num2;
    return &res;
}

```

## 5. 回调函数

将函数A作为参数传给函数B

一般都要结合函数指针使用

简单使用例：

```c
#include <stdio.h>
#include <string.h>
#include <stdbool.h>

//定义被调用函数
bool ICBC(int m);
bool CCB(int m);

//定义调用函数
void WBY(int a ,bool (*fp)(int));

int main(int argc, char const *argv[])
{
    int m = 0;
    char str[10];
    printf("请输入消费金额 \n");
    scanf("%d" ,&m);
    printf("请输入用于扣款的银行卡 \n");
    scanf("%s" ,str);

    if (!strcmp(str,"CCB"))
    {
        WPY(m ,CCB);
    }
    else if (!strcmp(str,"ICBC"))
    {
        WPY(m ,ICBC);
    }

    return 0;
}

void WPY(int m ,bool (*fp)(int))
{
    if (fp(m))
    {
        printf("扣款成功! \n");
    }
    else
    {
        printf("扣款失败! \n");
    }
    
}

bool CCB(int m)
{
    static int res = 100;//定义为静态变量，防止每次调用都要重新赋值
    if (m > res)
    {
        return false;
    }
    else
    {
        res -= m;
        printf("余额现有：%d \n" ,res);
        return true;
    }
}

bool ICBC(int m)
{
    static int res = 100;
    if (m > res)
    {
        return false;
    }
    else
    {
        res -= m;
        printf("余额现有：%d \n" ,res);
        return true;
    }
}


```

## 6. 内联函数

语法：

```c
static inline return_type function_name(parameter_list){function_body};
```

首先明确普通函数在调用时在栈中的进行步骤：&#x20;

1.  为调用的函数准备参数和返回地址空间&#x20;
2.  跳转到函数的地址，将参数传入&#x20;
3.  函数运行结束将返回值返回原来地方，删除为调用函数开辟的参数和返回地址空间 &#x20;

而**内联函数在调用函数时，是直接在调用处，把被调用函数整个拿过来**，省去了上述操作 &#x20;

内联函数主要可以提升代码运行速度 &#x20;

对于**过大的函数体，编译器不会将其作为内联函数编译，会当作普通函数进行编译**&#x20;

对于**递归函数也无法作为内联函数，递归函数依赖于函数地址**，因为递归时需要找到被调用的函数地址，而内联是不去找地址，直接在原地展开被调用函数的函数体

简单使用例：

```c
#include <stdio.h>

static inline int add(int num1 ,int num2);
int add2(int num1 ,int num2);

int main(int argc, char const *argv[])
{
    int n1 ,n2;
    printf("请输入两个正整数，用空格隔开\n");
    scanf("%d %d" ,&n1 ,&n2);

    printf("调用内联函数结果为：%d \n" ,add(n1 ,n2));
    printf("调用普通函数结果为：%d \n" ,add2(n1 ,n2));

    return 0;
}

static inline int add(int num1 ,int num2)
{
    return num1 + num2;
}

int add2(int num1 ,int num2)
{
    return num1 + num2;
}

```

## 7. 可变参数

即参数的数量和类型都是不定的

使用时必须添加对应头文件

```c
#include <stdarg.h>
```

声明语法

```c
return_type function_name(parameter1 ,...);
```

函数定义必须步骤：

**1 创建list**

```c
va_list list_name;
```

**2 将参数都放进list中**

```c
va_start(list_name ,last_parameter);
```

**3 使用时将参数从list中取出**

```c
va_arg(list_name ,parameter_type);
```

其中parameter\_type是指把参数按照parameter\_type的类型去解析

**4 清空列表**

```c
va_end(list_name);
```

简单使用例:

```c
#include <stdio.h>
#include <stdarg.h>

int sum_nums(int n ,...);

int main(int argc ,const char *argv[])
{
	printf("sum = %d \n" ,sym_nums(3 ,1 ,2 ,3 ,4));//前三项相加6

	return 0;
}

int sum_nums(int n ,...)
{
	int sum = 0;
	va_list list;//创建list

	va_start(list ,n);//前n个把参数都放进list

	for(size_t i = 0; i < n ;i++)
	{
		sum += va_arg(list ,int);
	}

	va_end(list);//清空列表
	return sum;
}
```

## 8. 结构体尺寸&地址对齐

首先明确地址对齐：

64位系统，CPU读取数据是一次读8byte，如果数据都是8byte一组排列，CPU读取就会很快，整体效率就会很高

关于结构体尺寸，只需要记住以下部分：

*   **结构体所占内存是按照结构体内部成员中，所占内存最大的基本成员的字节数进行增加**
*   **不同数据之间，为了实现对齐，会用无效字节进行填充，保证第一条**
*   **结构体整体所占内存大小必须是成员中所占内存最大成员的整数倍**
*   **若结构体内有数组或者子结构体，需要将其看作一个整体**

例如一个结构体里所占内存最大的基本类型成员是double类型的，那么这个结构体所占内存就必须是8的整数倍

## 9. 共用体

看起来和结构体很类似，区别在于所占用内存大小，以及数据有效性

**结构体：每一个成员都独立占有一块空间
共用体：所有成员都共用一个内存空间**

**共用体的存储大小遵循地址对齐规则**

区别举例：

```c
#include <stdio.h>
#include <string.h>

struct Student
{
    int age;
    char name[10];
};

union STudent
{
    int age;
    char name[10];
};

int main(int argc, char const *argv[])
{
    printf("结构体Student所占用内存为 %zu byte \n" ,sizeof(struct Student));//16
    printf("共用体STudent所占用内存为 %zu byte \n" ,sizeof(union STudent));//12

    //结构体由于每个成员都独立占有内存空间，因此其数据只要被赋值了以后，再使用就是赋值之后的值


    //创建一个Student变量
    struct Student S1 = {18 ,"张三"};
    //第一次调用查看age的值
    printf("S1.age = %d \n" ,S1.age);//会输出18

    //如果后面更改了name的值
    strcpy(S1.name ,"李四");
    //此时再次查看age的值
    printf("S1.age = %d \n" ,S1.age);//还是会输出18

    //创建一个STudent变量
    union STudent s2;
    s2.age = 18;
    //第一次调用查看age的值
    printf("s2.age = %d \n" ,s2.age);//18
    //查看name
    printf("s2.name = %s \n" ,s2.name);//空
    //如果更改了name值
    strcpy(s2.name ,"张三");
    //再次查看age的值
    printf("s2.age = %d \n" ,s2.age);//s2.age = -37173803
    //但是查看name
    printf("s2.name = %s \n" ,s2.name);//张三

    /*
    会发现更改name后age受到了影响，这是因为共用体内成员使用的是同一个内存空间，这就导致了同一时间下只有一个成员有效
    */

    return 0;
}

```

## 10. 枚举

*   枚举值必须是int类型，如果不赋值第一个默认为0，后面的依次加一
*   如果赋值第一个，后面的继续加1&#x20;
*   里面的值可以随便赋值，如果某一个没有赋值就是用前一个+1

简单使用例：

```c
#include <stdio.h>

enum Date
{
	Mon,//默认会赋值0
	Tus,
	Wen,
	Thr,
	Fri,
	Sta,
	Son
};

int main(int argc ,const char *argv[])
{
	for(size_t i = 0; i < Son; i++)
	{
		printf("今天星期 %d \n" ,i+1);
	}	

	/*
	今天星期 1 
	今天星期 2
	今天星期 3
	今天星期 4
	今天星期 5
	今天星期 6
	今天星期 7
	*/

	return 0;
}

```
