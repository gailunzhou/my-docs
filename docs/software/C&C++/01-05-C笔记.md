# C语法基础

## 1. 数据类型

### 1.1 数据类型分类

数据类型分为：

1.  基本类型：

    *   整形:

        *   有符号（signed）: short  int  long  long long
        *   无符号（unsigned）: short  int  long  long long
    *   字符型: char
    *   实型(浮点型): float  double
    *   枚举型: enum
2.  构造类型：

    *   数组(array)
    *   结构体: struct
    *   共用体: union
3.  指针类型
4.  空类型: void

#### 1.1.1 通过使用 **sizeof( )** 函数可获得指定变量、类型的所占内存大小

例1：获得指定变量内存大小

```c
#include <stdio.h>

int main()
{
	int a = 10;
	printf("%zu \n" ,sizeof(a));
	return 0;
}

```

例2：获得指定类型所占内存大小

```c
#include <stdio.h>

int main()
{	
	printf("%zu \n" ,sizeof(double));
	return 0;
}
```

**注意：**

函数 \*\*sizeof( )\*\*返回的类型是： **size\_t**

该类型在不同系统中定义的类型不同：

*   32位系统中：

    typedef unsigned int size\_t;
*   64位Linux系统中:

    typedef unsigned long size\_t;
*   64位Windows系统中：

    typedef unsigned long long size\_t;

而该类型的变量使用 \*\*printf()\*\*打印时，其格式符为 **%zu**

#### 1.1.2 可通过添加头文件的方式查看不同类型数据的最大，小值

例如：

```c
#include <stdio.h>
#include <limits.h>

int main()
{
    //1.有符号类型
    //1.1 short
    short sh1 = 1000;

    printf("short 类型最小值为: %hd \n" ,SHRT_MIN);
    printf("short 类型最大值为: %hd \n" ,SHRT_MAX);

	return 0;
}
```

**说明：**

其中

*   SHRT\_MIN ： short类型数据的最小值
*   SHRT\_MAX： short类型数据的最大值

对于浮点类型数据查看最大、小值：

```c
#include <stdio.h>
#include <float.h>

int main(int argc, char const *argv[])
{
    //浮点型
    //1.float

    printf("float 数据最小值为:%lf \n" ,FLT_MIN);
    printf("float 数据最大值为:%lf \n" ,FLT_MAX);

    return 0;
}

```

**注意：**

在对变量赋值为long long类型(有符号和无符号同理)时，需要在数值最后增加一个字母**L**

例如：

```c
#include <stdio.h>

int main()
{
	long long LL_i = 1000000L;
	printf("LL_i = %lld \n" ,LL_i);

	unsigned long long LL_ui = 11000000L;
	printf("LL_ui = %llu \n" ,LL_ui);

	return 0;
}
```

### 1.2 bool类型数据

使用该类型数据需要包含对应头文件：

```c
#include <stdbool.h>
```

且该类型数据所占用内存大小为**1字节**

```c
#include <stdio.h>
#include <stdbool.h>

int main()
{
	bool result = 0;
    if(result)
    {
        printf("result = 1 \n");
    }
    else
    {
        printf("result = 0 \n");
    }
	printf("bool类型数据所占内存大小为: %zu \n" ,sizeof(bool));//1字节

	return 0;
}
```

### 1.3 浮点型数据

该类型数据分为:

*   **float 单精度 ：有效位为整数位+小数位 <= 6位 ，**
*   **double 双精度 : 有效位为整数位+小数位 <= 15位**
*   **long double 长双精度 : 有效位为整数位+小数位 <= 18位**

三种类型，其中有效位数是指：

```c
#include <stdio.h>
#include <float.h>

int main()
{
	unsigned long long length;

	//1.float
	float f1 = 3.14159265358979323846f;
	printf("直接输出: f1 = %f \n" ,f1);//3.141593 ，最后一个3是约等于
	printf("超过有效位输出: f1 = %.8f \n" ,f1);//3.14159274
	
	length = sizeof(float);
	printf("float数据所占内存大小为: %llu \n" ,length);//4

	//2.double
	double d1 = 3.14159265358979323846;
	printf("直接输出: d1 = %f \n" ,d1);//3.141593
	printf("超过有效位输出: d1 = %.16f \n" ,d1);//3.14159265358979323851

	length = sizeof(double);
	printf("double数据所占内存大小为: %llu \n" ,length);//8

	//3.long double
	long double ld1 = 3.14159265358979323846L;
	printf("直接输出: ld1 = %Lf \n" ,ld1);//3.141593
	printf("超过有效位输出: ld1 = %.20Lf \n" ,ld1);//3.14159265358979323851
 	//还可以按照 %m.nf 的方式进行输出，其中m是 整数部分 + 1位小数点 + 小数部分 的长度 ，n是小数部分的长度
    printf("ld1 = %30.20Lf \n" ,ld1);
    //如果整数位不足，可以补0
    printf("ld1 = %030.20Lf \n" ,ld1);

	length = sizeof(long double);
	printf("long double数据所占内存大小为: %llu \n" ,length);//16

	printf("long double 数据最小值为:%Lf , 使用科学计数法为: %E \n" ,LDBL_MIN ,LDBL_MIN);//最小值是0
    printf("long double 数据最大值为:%Lf , 使用科学计数法为: %E \n" ,LDBL_MAX ,LDBL_MAX);

	return 0;
}

```

**说明：**

当超过有效位显示时，其超过位的数据和原始数据不同，即精度降低

**注意：**

*   单精度类型数据**float**在对数据进行赋值时最后需要加上**f**
*   double类型数据在printf()时格式符用%f，但**在scanf()时必须用%lf，用%f会出错**
*   长双精度类型数据**long double**在对数据进行赋值时需要加上**L**，并且在使用 printf() 进行格式调用时要加**L：**

```c
long double lb1 = 3.14159265358979323846L;

printf("long double 数据 lb1 = %Lf \n" ,lb1);
```

### 1.4 字符类型

#### 1.4.1 char类型

&#x20;char类型数据是按照ASCII码对应的，而ASCII码仅有0\~127个字符，因此char类型数据仅需要 **1byte** 内存即可

即char所代表范围是 -128 \~ 127

unsigned char 所代表范围是 0 \~ 255

#### 1.4.2 作为字符类型数据，可以通过 printf() 函数查看其在ASCII码表中所代表的字符内容 ，和其对应的10进制数

例如：

```c
#include <stdio.h>

int main(int argc, char const *argv[])
{
    /* code */
    //字符类型数据
    // 1. char
    char c1 = 'C';
    printf("c1的字符为: %c ,c1在ASCII码表中的内容为: %d \n" ,c1 ,c1);// C  67
    char c2 = 94;
    printf("c2的字符为: %c ,c2在ASCII码表中的内容为: %d \n" ,c2 ,c2);// ^  94

	return 0;
}
```

#### 1.4.3 转义字符

##### 1.4.3.1 '\n' 换行符

例如：

```c
//2.1 '\n' : 回车
char c3 = '\n';
printf("%c" ,c3);
```

##### 1.4.3.2 '\t' 制表符

例如：

```c
//2.2 '\t' : 制表（4个空格）
printf("1111\t2222 \n");
```

##### 1.4.3.3 '\b' 退格符

例如:

```c
//2.3 '\b' : 退格（回退1格）
printf("111111,6个1,没有加退格符 \n");
printf("111111\b,加了退格符 \n");
```

##### 1.4.3.4 '\0' 空符

例如:

```c
char c4 = '\0';
if(c4 == '\0')
{
   printf("c4是空");
}
else
{
   printf("c4非空");
}
```

##### 1.4.3.5 '\ddd' 代表一个三位八进制数

例如:

```c
char c5 = '\101';
printf("c5的字符内容为: %c ,其在ASCII码表中的内容为 : %d \n" ,c5 ,c5);//A  65
```

##### 1.4.3.6 '\xhh' 代表一个2位16进制数

```c
char c6 = '\x2A';
printf("c6的字符内容为: %c ,其在ASCII码表中的内容为 : %d \n" ,c6 ,c6);//*  62
```

**说明：**

1.4.3.5 和 1.4.3.6 虽然一个是3位的8进制数，另一个是2位的16进制数，但其本质是一个字符类型的数据，因此赋值时不要超过其数据类型的限制范围，若超过则不识别

其过程可以理解为：

由于**数据在电脑当中都是2进制，而8进制、16进制、10进制都只是方便人看，本质是一样的**，因此虽然赋值时是以8进制、16进制的方式赋值，电脑得到的还是2进制，而电脑也有ASCII码表中的数据的所有2进制结果，所以直接按照你所给的值去找对应的即可

##### 1.4.3.7 还原本意操作

反斜杠符号 \ 的使用，例如：

```c
printf("\\\\ \n");
printf("\" \n");
```

## 1.5 常量

*   通过添加 const 关键字声明该变量是一个常量
*   const仅有归类作用，所定义数据的类型还是需要确认，如int ,float ,char等
*   常量在定义时**必须初始化**，否则会出现脏数据
*   常量是**只读**属性，即初始化赋值后不可更改

例如：

```c
#include <stdio.h>

int main(int argc, char const *argv[])
{
    const int i = 10;
    printf("i = %d \n" ,i);// 10

    return 0;
}

```

## 1.6 变量

*   重点在于全局变量和局部变量的作用域：&#x20;

    *   **全局变量作用于其所属的当前文件全部地方**&#x20;
    *   **局部变量仅作用于函数内部**
*   全局变量定义后存在默认值
*   **局部变量定义后不存在默认值，因此需要赋值初始化（如果紧跟的后面没有赋值操作的话）**

例如：

```c
#include <stdio.h>

int variable1 = 10;
int variable2 ;

void variable_learning(void)
{
    int variable3 = 40;
    printf("函数内部变量仅作用于函数内 variable3 = %d \n" ,variable3);

    printf("全局变量作用于当前文件全部地方 variable1 = %d \n" ,variable1);
    printf("全局变量作用于当前文件全部地方 variable2 = %d \n" ,variable2);
}

int main(int argc, char const *argv[])
{
    printf("全局变量作用于当前文件全部地方 variable1 = %d \n" ,variable1);
    printf("全局变量作用于当前文件全部地方 variable2 = %d \n" ,variable2);

    //通过调用函数实现
    variable_learning();

    return 0;
}

```
