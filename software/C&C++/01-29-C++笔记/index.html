    C++语法基础

    1. 面向过程&面向对象

    1.1 面向过程

    思想核心：功能分解，自顶向下，逐层细化

    1.2 面向对象

    通过多代码模块，每个模块只提供特定功能，彼此相互独立，增加了代码的复用率

    对象的三大特点：

    • 封装：类将成员变量和成员函数封装在内部，根据需要设置访问权限，通过成员函数管理内部变量状态
    • 继承：类可以被别的类继承，继承的类是子类，目的是为了减少共用代码重复
    • 多态：多态是指允许不同类的对象对同一消息作出响应的能力，即同一个接口可以有多个不同的实现

    关于访问权限：

    • private：私有的，只能在本类中被访问
    • protected：受保护的，仅允许本类和子类中访问
    • public：公开的，允许外部访问

    1.3 类的创建

    使用关键字class

    class 类名 
{ 
    访问权限:
        数据类型 属性名(变量名);
    访问权限:
        函数  
};

    例如

    class Demo
{
    //访问权限
    private:
        int num1;
    protected:
        char c1;
    public:

    1.5 类在其他文件实现

    每一个类应该有一个自己的头文件（声明）和对应的源文件（定义）

    练习：设计一个 Student类，Student 类具有stuno, name 和 age 属性，提供初始化函数(Init)，并提供对 stuno,name 和 age 的读写函数(set，get)，但必须确保 age 的赋值在有效范围内(7-25),超出有效范围，则拒绝赋值，并提供方法输出学号姓名和年龄

    头文件：

    #pragma once //相当于#ifndef ... #define ... #endif

class Student
{
private:
    int stuno;
    const char* name;//C++中字符串为const char
    int age;
public:
    void setStuno(int the_stuno);
    int getStuno(void);

    void setName(const char* the_name);
    const char* getName(void);

    void setAge(int the_age);
    int getAge(void);

    void Student_Init(int the_stuno, const char* the_name, int the_age);
    void Print_StuInfo(void);
};

    源文件：

    #include "Student.h"
#include <iostream>
using namespace std;

void Student::setStuno(int the_stuno)
{
    stuno = the_stuno;
}

int Student::getStuno(void)
{
    return stuno;
}

void Student::setName(const char* the_name)
{
    name = the_name;
}

const char* Student::getName(void)
{
    return name;
}

void Student::setAge(int the_age)
{
    if (the_age < 7 || the_age > 25)
    {
        cerr << "age is illegal " << endl;
        return ;
    }
    age = the_age;
}

int Student::getAge(void)
{
    return age;
}

void Student::Student_Init(int the_stuno, const char* the_name, int the_age)
{
    stuno = the_stuno;
    name = the_name;
    if (the_age < 7 || the_age > 25)
    {
        cerr << "age is illegal " << endl;
        return;
    }
    age = the_age;
}

void Student::Print_StuInfo(void)
{
    cout << "stuno : " << stuno << "\tname : " << name << "\tage : " << age << endl;
}

    主函数中调用：

    #include <iostream>
#include "Student.h"//包含对应头文件
using namespace std;

int main()
{
    //实例化Student类
    Student stu;
    stu.Student_Init(1001, "A", 12);

    Student stu2;
    stu2.setStuno(1002);

    stu2.setName("B");
    stu2.setAge(8);
    //打印信息
    stu2.Print_StuInfo();

    return 0;
}

    2. 构造函数&析构函数

    2.1 构造函数

    2.1.1 构造函数的作用

    实例化类时，为对象的属性成员赋初值，该函数由编译器调用，无需手动调用

    2.1.2 构造函数的相关语法

    构造函数的函数名一定要和类名完全相同

    class 类名
{
private:
    属性成员  成员名;
    ...
public:
    //构造函数
    类名(参数列表)
    {
        ...
    }

};
    • 构造函数无返回值，所以没有return type（包括void）
    • 构造函数支撑重载，即可以有参数
    • 构造函数若有参数，要和类的属性成员保持一致
    • 构造函数权限一般为public

    • 构造函数按有无参数可分为：

      • 有参构造函数
      • 无参构造函数

      • 按类型可分为：

      • 普通构造函数

      • 拷贝构造函数

    注意：

    编译器会默认给类一个无参构造函数，但是如果自定义了构造函数（无论有参还是无参）都会直接屏蔽编译器提供的默认构造函数

    class Demo
{
private:
    int a;
    int b;
public:
    //自定义了构造函数后会屏蔽编译器提供的默认构造函数
//以下两个都是普通构造函数
    //无参构造函数
    Demo()
    {
        a = 10;
        b = 20;
        cout << "this is a no param constructor " << endl;
    }
    //构造函数支撑重载
    //有参构造函数
    Demo(int num1 ,int num2)
    {
        a = num1;
        b = num2;
        cout << "this is a provided constructor " << endl;
    }
};

    调用上面的构造函数

    #include <iostream>
using namespace std;

class Demo
{
private:
    int a;
    int b;
public:
    //自定义了构造函数后会屏蔽编译器提供的默认构造函数
//以下两个都是普通构造函数
    //无参构造函数
    Demo()
    {
        a = 10;
        b = 20;
        cout << "this is a no param constructor " << endl;
    }
    //构造函数支撑重载
    //有参构造函数
    Demo(int num1 ,int num2)
    {
        a = num1;
        b = num2;
        cout << "this is a provided constructor " << endl;
    }
};

int main()
{
    //在实例化类的时候调用构造函数
    Demo demo1;//隐式调用无参构造函数------>推荐

    Demo demo2 = Demo();//显式调用无参构造函数

    Demo demo3(6 ,10);//隐式调用有参构造函数----->推荐

    Demo demo4 = Demo(15 ,30);//显示调用有参构造函数

    return 0;
}

    特殊情况：

    如果有参构造函数只有一个参数，实例化类的时候可以通过隐式转换来构造：

    #include <iostream>
using namespace std;

class Demo
{
private:
    int num1;
    int num2;
public:
    //有参构造函数
    Demo(int n1)//只有一个参数
    {
        num1 = n1;
        num2 = 10;
    }
    //无参构造函数
    Demo()
    {
        num1 = 0;
        num2 = 0;
    }
};

int main()
{
    //实例化类
    Demo demo1 = 5;
    /*
    此处的意思不是将demo1赋值为5，且C++中对类型有严格要求，不同类型无法直接赋值
    此处的意思是： Demo demo1 = Demo(5);
    调用了只有一个参数的有参构造函数
    */

    return 0;
}
    2.1.2.1 如何禁用隐式转换

    在只有一个参数的有参构造函数前面加 explicit 关键字，比如上例就应该为

    #include <iostream>
using namespace std;

class Demo
{
private:
    int num1;
    int num2;
public:
    //有参构造函数
    explicit Demo(int n1)//只有一个参数，但增加了explicit关键字
    {
        num1 = n1;
        num2 = 10;
    }
    //无参构造函数
    Demo()
    {
        num1 = 0;
        num2 = 0;
    }
};

int main()
{
    //实例化类
    //Demo demo1 = 5; //--------->此时这样使用就会报错，会认为是在进行赋值操作
    //就只能按照有参构造函数的调用方式来调用
    Demo demo1(5);

    return 0;
}

    2.1.3 拷贝构造函数

    当使用已实例化的对象来实例化新的对象时就会使用到拷贝构造函数

    本质也是构造函数，因此编译器也会默认给类提供一个默认的拷贝构造函数

    内容大致如下：(实际不一定，但意思一样)

    class Demo
{
private:
    int num1;
    int num2;
public:
    Demo(const Demo& demo)
    {
        num1 = demo.num1;
        num2 = demo.num2;
    }

};

    说明：

    • 为什么参数是 const Demo \&demo？

      • 首先 Demo& demo 是demo 的引用，减少创建内存空间，通过引用获取值
      • 然后拷贝，则不要修改被拷贝对象的值，因此是 const

    实际使用：

    #include <iostream>
using namespace std;

class Demo
{
private:
    int num1;
    int num2;
public:
    Demo()
    {
        num1 = 0;
        num2 = 0;
    }
    Demo(const Demo& demo)
    {
        num1 = demo.num1;
        num2 = demo.num2;
    }

};

int main()
{
    //实例化类
    Demo demo1;

    //拷贝
    Demo demo2 = demo1;

    return 0;
}

    注意：

    • 自定义有参、无参构造函数时，不会屏蔽编译器提供的拷贝构造函数
    • 给对象取别名时不会调用拷贝构造

    只有基本数据类型的属性成员，调用拷贝后结果相同

    #include <iostream>
using namespace std;

class Demo
{
private:
    int num1;
    int num2;
    double d1;
public:
    void setNum1(int n1)
    {
        num1 = n1;
    }
    int getNum1(void)
    {
        return num1;
    }

    void setNum2(int n2)
    {
        num2 = n2;
    }
    int getNum2(void)
    {
        return num2;
    }

    void setD1(double d)
    {
        d1 = d;
    }
    double getD1(void)
    {
        return d1;
    }

    Demo()
    {
        num1 = 0;
        num2 = 0;
        d1 = 0.0;
    }
    Demo(const Demo& demo)
    {
        num1 = demo.num1;
        num2 = demo.num2;
        d1 = demo.d1;
    }

};

int main()
{
    //实例化类
    Demo demo1;

    //拷贝
    Demo demo2 = demo1;

    //打印demo2_1和demo2_2
    cout << "demo2_1.num1 = " << demo2_1.getNum1() << "\t demo2_1.num2 = " << demo2_1.getNum2() << "\tdemo2_1.d1 = " << demo2_1.getD1() << endl;
    cout << "demo2_2.num1 = " << demo2_2.getNum1() << "\t demo2_2.num2 = " << demo2_2.getNum2() << "\tdemo2_2.d1 = " << demo2_2.getD1() << endl;
    /*
    demo2_1.num1 = 0         demo2_1.num2 = 0       demo2_1.d1 = 0
    demo2_2.num1 = 0         demo2_2.num2 = 0       demo2_2.d1 = 0
    */

    return 0;
}

    普通对象作为函数返回值返回时，可能会调用拷贝构造（不同编译器结果不同）

    Demo1 fun1()
{
    Demo1 o1(10);   // 初始化对象，调用一次构造函数
    return o1;  // 返回时，因为o1的生命周期已经到了，所以会在栈的临时区域开辟一个空间，临时空间的值就是o1的值，这会调用一次拷贝构造。然后外部的o2就是使用的临时空间的这个对象
}

int main() {
    Demo1 o2 = fun1();
}

    在现在大多数的编译器中，都已经优化了上述代码，即不会在临时区域再开辟一个空间，而是直接将o2直接指向o1的所在空间，将o1的生命周期延长了，但是在外面，只能使用o2操作这个对象

    2.1.4 深拷贝&浅拷贝

    2.1.4.1 浅拷贝

    就是上面的例子：

    浅拷贝指的是在创建新对象时,如果是基本数据类型，拷贝构造函数会将原始对象的基本类型成员的值直接复制给新对象的相应成员。这意味着新对象拥有自己的副本，对新对象的成员所做的任何更改都不会影响到原始对象。

    2.1.4.2 深拷贝

    当类的属性成员存在指针这样的数据类型，再使用浅拷贝，使用过程中就会出错

    例如

    #include <iostream>
#pragma warning(disable:4996)
using namespace std;

class Demo
{
private:
    int num1;
    int num2;
    double d1;
    char *str;//指针类型
public:
    void setNum1(int n1)
    {
        num1 = n1;
    }
    int getNum1(void)
    {
        return num1;
    }

    void setNum2(int n2)
    {
        num2 = n2;
    }
    int getNum2(void)
    {
        return num2;
    }

    void setD1(double d)
    {
        d1 = d;
    }
    double getD1(void)
    {
        return d1;
    }

    void setStr(char *new_str)
    {
        strcpy(str, new_str);
    }
    char *getStr(void)
    {
        return str;
    }

    Demo()
    {
        num1 = 0;
        num2 = 0;
        d1 = 0.0;
        str = NULL;
        cout << "this is a no param constructor in Demo " << endl;
    }   
    Demo(int n1, int n2, double d, char* input)
    {
        num1 = n1;
        num2 = n2;
        d1 = d;
        //先分配内存
        str = new char[strlen(input) + 1];
        strcpy(str ,input);
        cout << "this is a provided constructor in Demo " << endl;
    }
    Demo(const Demo& demo)//浅拷贝
    {
        num1 = demo.num1;
        num2 = demo.num2;
        d1 = demo.d1;
        if (demo.str == NULL)
        {
            str = NULL;
        }
        else
        {
            str = demo.str;
        }

        cout << "this is a provided copy constructor in Demo " << endl;
    }

};

int main()
{
    //实例化类
    Demo demo1;

    //拷贝
    Demo demo2 = demo1;

    //打印demo2_1和demo2_2
    cout << "demo2_1.num1 = " << demo2_1.getNum1() << "\t demo2_1.num2 = " << demo2_1.getNum2() << "\tdemo2_1.d1 = " << demo2_1.getD1() << endl;
    cout << "demo2_2.num1 = " << demo2_2.getNum1() << "\t demo2_2.num2 = " << demo2_2.getNum2() << "\tdemo2_2.d1 = " << demo2_2.getD1() << endl;
    /*
    demo2_1.num1 = 0         demo2_1.num2 = 0       demo2_1.d1 = 0

    会发现只是对demo2_4中的字符串进行修改，却影响到了demo2_3

    原因：

    修改字符串操作中，是直接对原字符串使用strcpy，strcpy不会修改原来这块内存空间的地址，而是修改其中的内容，而浅拷贝对于指针类型，是直接将旧对象的指针属性的地址复制给新对象的指针属性，因此两个属性成员都指向同一块内存空间，内容修改了，都会受影响

    解决办法1：

    将修改字符串操作中改为：

    void setStr(char* new_str)
{
    if(str != nullptr)
    {
        delete []str;//先释放旧内存
    }
    str = new char[strlen(new_str) + 1];//用新内存来存储新的字符串
    strcpy(str, new_str);
}

    解决方法2：

    深拷贝：

    Demo(const Demo& demo)//深拷贝
{
    num1 = demo.num1;
    num2 = demo.num2;
    d1 = demo.d1;
    if (demo.str == NULL)
    {
        str = NULL;
    }
    else
    {
        str = new char[strlen(demo.str) + 1];
        strcpy(str, demo.str);
    }

    cout << "this is a provided copy constructor in Demo " << endl;
}

    这样拷贝会为新对象的指针属性成员分配一个内存空间存储内容，而不是直接复制粘贴地址

    2.1.5 析构函数

    析构函数主要用于对象销毁前系统自动调用，执行一些清理工作。

    ​析构函数语法： 析构函数函数名是在类名前面加”\~”组成,没有返回值，不能有void,不能有参数，不能重载

    注意：

    析构函数和构造函数一样，如果用户没有提供，那么系统会默认提供一个空的析构函数

    调用过程中是先调用析构函数，再释放对象

    类中若无指针属性成员则不需要自定义析构函数，编译器提供的默认析构函数即可

    析构函数运行过程和栈类似:

    //析构函数
class Demo3
{
private:
    int a;
    int b;
public:
    void setA(int n1)

        a = n1;

        b = n2;

    当类中有指针属性成员时必须要自定义析构函数

    因为指针成员被释放时，其指向的内存空间不会自动释放，可能会造成内存泄漏，因此需要手动释放

    //必须自定义析构函数的情况：有指针属性的成员
class Demo4
{
private:
    char* name;
public:
    void setName(char* new_name)
    {
        strcpy(name, new_name);
    }
    char* getName(void)
    {
        return name;
    }

    //自定义有参构造
    Demo4(char* new_name)
    {
        name = new char[strlen(new_name) + 1];
        strcpy(name, new_name);
        cout << "this is a constructor in Demo4 name :" << name << endl;
    }
    //析构函数
    ~Demo4()
    {
        if (name != nullptr)//如果有
        {
            //释放
            delete name;
        }
        cout << "this is a destructor in Demo4 " << endl;
    }
};

    注意：

    默认情况下，c++编译器至少为我们写的类增加 3 个函数

    1．默认构造函数(无参，函数体为空)

    2．默认析构函数(无参，函数体为空)

    3．默认拷贝构造函数，对类中非静态成员属性简单值拷贝

    如果用户定义拷贝构造函数，c++不会再提供任何默认构造函数 如果用户定义了普通构造(非拷贝)，c++不在提供默认无参构造，但是会提供默认拷贝构造

    2.1.6 初始化列表

    所谓初始化列表，就是在执行构造函数时，通过:后面的代码为成员赋初始值

    语法： 构造函数(参数类型 参数名) :成员名(参数名)

    就会自动把参数的值赋值给对应的成员

    且会先执行初始化列表，再执行构造函数体中的内容

    初始化列表主要是用于解决以下情况：

    当类对象作为其他类的成员时，实例化新类成员时会访问对象成员并实例化，但是当对象成员没有默认的构造函数，或者想指定调用某个构造函数以及子类的成员属性是私有的，是无法访问并初始化的
