    C++

    1. 运算符重载

    当需要对自定义的数据类型（类）进行输入输出（cout ，cin）时会报错说没有对应的方法，这是因为输入输出函数只对内部早已定义好的一些数据类型有对应的方法，为了解决这个问题，C++中可以使用运算符重载

    概述

    运算符重载(面试题)：允许程序员对已有的运算符进行重定义，让其可以对自定义数据像内部已有的数据一样进行运算

    只是一种语法上的方便，本质是另一种函数调用的方式

    语法

    运算符重载本质就是函数重载

    return_type operator@(parametor_list);

    其中@就是要重载的运算符（比如 << \ >> \ + \ =）

    参数列表

    如果有一个参数称为一元运算符，有两个是二元运算符，超过两个则是多元运算符

    分为两种情况：

    1. 作为全局函数

    全局函数时，假设参数列表中有N个参数，那么实际使用时就应该传入N个参数

    2. 作为类中的成员函数

    类的成员函数时，第一个参数是this指针，也就是说，如果是一元运算符，就没有参数，如果是二元，就只有一个参数，参数列表有N个参数，实际就只有N-1个参数

    使用注意

    大部分运算符都可以重载，这里只重点提不可重载的运算符：

    • .
    • ::
    • .*
    • ?:
    • sizeof

    不建议重载的运算符：

    1. &&
    2. ||

    原因：以上两个运算符有短路运算（&&前面为假则结果为假，&&后面的表达式不执行；||前面为真则结果为真，||后面的表达式不执行），使用重载无法实现短路运算

    2. 实例

    假设现在已经定义了一个类

    class Stu
{
private:
    int stuNo;
    string stuName;
    int stuAge;
public:
    Stu()
    {
    }
    Stu(int stuNo, string stuName, int stuAge) :stuNo(stuNo), stuName(stuName), stuAge(stuAge)
    {

    }
};

    要想使用cin和cout正常输入输出类对象cout << stu1 << endl;也就需要操作类的成员变量，而上面定义的成员变量都是私有的，也没有定义set和get函数去操作，所以要将运算符重载函数作为类的友元函数

    class Stu
{
    friend ostream& operator<<(ostream& cout, Stu& stu);
    friend istream& operator>>(istream& cin, Stu& stu);
private:
    ... ...
};

    当作为类的友元函数后，相当于是做了函数声明，无需再次手动声明，可直接编写实现

    1. << 和 >>

    1.1 <<

    重载输入运算符

    // 重载 >> 输入运算符
istream& operator>>(istream& cin, Stu& stu)
{
    cin >> stu.stuNo >> stu.stuName >> stu.stuAge;
    return cin;
}

    1.2 >>

    重载输出运算符

    // 重载 << 输出运算符
ostream& operator<<(ostream &cout,Stu &stu)
{
    cout << "stuNo=" << stu.stuNo << " stuName=" << stu.stuName << " stuAge=" << stu.stuAge << endl;
    return cout;
}

    说明

    这里为什么输入输出的返回值一个是istream&对应的cin，另一个是ostream&对应的cout？

    因为输入输出存在连续输入、连续输出的写法：

    cin << a << b << c << d;

    cout >> stu1 >> stu2 >> stu3 >> endl;

    这种连续的写法其实可以拆分成以下形式（本质也是以下形式）:

    cin << a; cin << b; cin << c; cin << d;

    cout >> stu1; cout >> stu2; cout >> stu3; cout >> endl;

    所以其实就是将下一个要使用的cin和cout隐藏了，<<和>>的返回值就是对应的cin和cout

    2. =

    如果想使用=用已有的类对象去创建新的类对象，就需要对=进行重载

    一个类默认存在一个赋值运算函数，但是就像浅拷贝一样，当类成员变量存在指针类型时，只能简单复制指针的值，无法复制指针所指向地址的内容，会引起共享资源冲突，为了避免这种情况就需要重载赋值运算符

    重载赋值运算符一般是作为类的成员函数

    //重载 = 赋值运算符
    Stu operator=( Stu stu2)
    {
        this->stuAge = stu2.stuAge;
        this->stuName = stu2.stuName;
        this->stuNo = stu2.stuNo;
        return *this;
    }
