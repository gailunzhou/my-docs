    C数据结构

    1. 图

    1.1 图的基本概念

    顶点（vertex）：图中的每个节点就是顶点。

    边（edge）：图中两个顶点之间的线就叫做边。

    路径：路径就是从某个顶点到另一个顶点所要经过的顶点序列。

    路径长度：一条路径上经过的边的数量。

    回路：一条路径的起点和终点为同一个顶点。

    度（Degree）：在无向图中，点的度指与该点相连的边的数量。在有向图中，分为出度和入度，指向该点的边数称为入度；反之，则称为出度。有向图某点度的大小等于该点出度和入度之和。

    无向图：所有的边都没有方向。

    有向图：所有的边都有方向。

    1.2 图的存储方式

    1.2.1 二维数组

    例如：

    0--------1

    | \ |

    | \ |

    | \ |

    | \ |

    2---------3

    对应的二维数组就是（1表示有边，0表示无边）

    0 1 2 3

    -----------

    0 | 0 1 1 1

    1 | 1 0 0 1

    2 | 1 0 0 1

    3 | 1 1 1 0

    1.2.2 链表

    例如：

    0--------1

    | \ |

    | \ |

    | \ |

    | \ |

    2---------3

    对应的链表为（每一个链表的节点都代表一个可以直接到达的顶点）

    0 | ->1 ->2 ->3

    1 | ->0 ->3

    2 | ->0 ->3

    3 | ->1 ->0 ->2

    1.3 图的搜索

    1.3.1 BFS（广度优先搜索）

    BFS算法是一个分层搜索的过程，和树的层序遍历算法类同，它也需要一个队列以保持遍历过的顶点顺序，以便按出队的顺序再去访问这些顶点的邻接顶点。

    1.3.2 DFS（深度优先搜索）

    它从图中某个节点v出发，访问此顶点，然后从v的未被访问的邻接点出发深度优先遍历图，直至图中所有和v有 路径相通的顶点都被访问到。若图中尚有顶点未被访问，则另选图中一个未曾被访问的顶点作起始点，重复上述过程，直至图中的所有顶点都被访问到为止。

    下面以无边图，BFS搜索为例

    2.1 创建图

    直接相邻的顶点结构体：（链表中的节点）

    //图中相邻节点的结构体
typedef struct graph_node
{
    //相邻节点索引
    int index;
    //下一个顶点
    struct graph_node *next;
}graph_node;

    所有顶点的一个结构体：（链表中的头）

    //顶点结构体
typedef struct vertex
{
    graph_node *head;
}vertex;

    图结构体：（类似于哈希表，用一个数组来存储所有的顶点，这里就是用一个数组来存储每一个链表的头）

    //图结构体
typedef struct graph
{
    //顶点个数
    int vertex_num;
    //顶点数组
    vertex vertex_array[MAX_GRAPH_SIZE];
}graph;

    创建图函数

    //创建图
graph *create_graph(int v_num)
{
    graph *new_graph = (graph *)calloc( 1 ,sizeof(graph));
    if (new_graph == NULL)
    {
        printf("创建图失败，内存分配失败\n");
        return NULL;
    }
    //获取节点数量
    new_graph->vertex_num = v_num;
    //初始化顶点数组
    for (size_t i = 0; i < v_num; i++)
    {
        new_graph->vertex_array[i].head = NULL;//最开始都为NULL，后续填入对应顶点的地址(因为存储的是一个链表)
    }
    printf("图已创建\n");
    return new_graph;
}

    由于是无边图，每一个点都是双向的，这里创建图中的每一个点，再添加好边

    //添加边:双向添加，无向图
void add_edge(graph *graph_ad ,int src ,int dest)
{
    //src--->dest
    //创建src
    graph_node *new_node = (graph_node *)calloc(1 ,sizeof(graph_node));
    if (new_node == NULL)
    {
        printf("创建新节点失败，内存分配失败\n");
        return ;
    }
    //添加src到dest的边 ↓
    new_node->index = dest;//相邻顶点为dest
    //从src所属链表的头部插入
    new_node->next = graph_ad->vertex_array[src].head;//将原来的头部节点作为新节点的下一个节点
    //更新头部节点为新节点
    graph_ad->vertex_array[src].head = new_node;

    //dest--->src
    //创建dest
    new_node = (graph_node *)calloc(1 ,sizeof(graph_node));
    if (new_node == NULL)
    {
        printf("创建新节点失败，内存分配失败\n");
        return ;
    }
    //添加dest到src的边 ↓
    new_node->index = src;//相邻节点为src
    //从dest所属链表的头部插入
    new_node->next = graph_ad->vertex_array[dest].head;
    //更新dest所属链表的头节点
    graph_ad->vertex_array[dest].head = new_node;

    printf("双边添加完成\n");
}

    2.2 BFS遍历

    用一个bool数组来记录哪些顶点访问过，用队列来记录要访问的顶点，再用一个数组记录路径（这个是重点）

    路径的记录方式：

    以路径数组的下标作为被访问顶点的编号，而内容填入访问该顶点的顶点编号

    例如：

    path[2] = 3

    意思访问顶点2的是顶点3

    由于路径是从起点开始记录的，因此可以通过倒推得出路径

    path[6] = {0 , 0 , 1 , -1 ,-1 ,-1 };

    意思是从0开始，访问0号节点的是0自己，然后0访问了1号节点，然后1访问了2号节点，即路径为

    0--->1--->2

    //BFS广度优先遍历
bool BFS(graph *graph_ad ,int start ,int end ,int path[])
{
    //获取当前顶点个数
    int num_ofvertex = graph_ad->vertex_num;
    //定义顶点访问状态数组
    bool visited[num_ofvertex];
    //定义要进行查找的顶点队列
    int queue[num_ofvertex];
    //定义队首和队尾在队列中的索引---->队首和队尾这里用写入和读取位置理解更好
    int front = 0 ,rear = 0;
    //从起点开始入队
    queue[rear ++] = start;
    //入队时起点标记自己已经被访问了
    visited[start] = true;

    //当队列中还有没被访问的顶点时继续访问
    while (front < rear)//读取的位置小于写入的位置时说明还没读完
    {
        //获取出队的顶点
        int current = queue[front ++];
        //找到这个顶点的链表头（找它有哪些直接相邻的顶点）
        graph_node *temp = graph_ad->vertex_array[current].head;
        while (temp != NULL)//从表头找到表尾
        {
            //找到表头顶点的相邻顶点
            int neighbor = temp->index;
            //判断是否已经访问过
            if (visited[neighbor] != true)
            {
                //没有被访问则修改访问状态
                visited[neighbor] = true;
                //没有被访问过则加入队中后续访问
                queue[rear ++] = neighbor;
                //记录是哪个顶点访问了该顶点
                path[neighbor] = current;
            }
            //判断该顶点是否就是要找的结束顶点
            if (neighbor == end)
            {
                printf("已找到\n");
                return true;
            }
            //否则就找下一个顶点
            temp = temp->next;
        }

    }
    printf("未找到终点\n");
    return false;
}

    2.3 打印路径（重点）

    //打印路径
void show_path(int path[] ,int start ,int end)
{
    if (start == end)
    {
        printf("%d ",start);
    }
    else if (path[end] == -1)
    {
        printf("未找到路径...\n");
    }
    else
    {
        show_path(path ,start ,path[end]);//使用了递归
        printf("%d " ,end);
    }

}

    2.4 主函数

    #include <stdio.h>
#include "..\inc\graph.h"

int main(int argc, char const *argv[])
{
    graph *new_graph = create_graph(6);

    //添加边
    add_edge(new_graph,0,1);
    add_edge(new_graph,0,4);
    add_edge(new_graph,1,2);
    add_edge(new_graph,1,4);
    add_edge(new_graph,2,3);
    add_edge(new_graph,2,4);
    add_edge(new_graph,3,5);
    add_edge(new_graph,4,5);

    //初始化路径
    int path[6] = {-1};
    //起点和终点
    int start = 0 ,end = 0;
    printf("请输入要查找的起点和终点:");
    scanf("%d %d" ,&start ,&end);

    if (BFS(new_graph ,start ,end ,path))//如果找到了路径
    {
        printf("%d 到 %d的最短路径为：\n" ,start ,end);
        show_path(path ,start ,end);
        printf("\n");
    }

    return 0;
}
