    C++基础

    1. C++和C的联系

    • C++是C的扩展，是C语言的超集

    2. C++和C的区别

    • C++在C语言的基础上添加了面向对象编程和泛型编程

    3. C++的简单入门程序

    #include <iostream>

int main()
{
    std:: << "Hello world!" << std::endl;//运行后输出Hello world!

    return 0;
}

    4. C++的输入和输出

    C++的输入输出都包含在 \ 中

    #include <iostream>

    4.1 输入

    标准输入:

    std::cin >> ...
    • std 命名空间
    • \:: 作用域运算符
    • cin 标准输入
    • >> 提取操作符
    #include <iostream>

int main()
{
    int input_num = 0;
    std::cout << "Please input a int type num:" << std::endl;
    std::cin >> input_num;
    std::cout << "input_num:" << input_num << std::endl;

    //多个连续输入
    float input_f = 0.0;
    char c1 = '\0';

    std::cout << "Please input a int ,float and a char each one with a space:" << std::endl;
    std::cin >> input_num >> input_f >> c1;
    std::cout << "input_num: " << input_num << " input_f: " << input_f << " c1: " << c1 << std::endl;

    return 0;
}

    4.2 输出

    标准输出

    std::cout << ... << std::endl;
    • std 命名空间
    • \:: 作用域运算符
    • cout 标准输出
    • << 重载后输出运算符
    #include <iostream>

int main()
{
    int a = 100;
    float b = 1.123f;
    char c = 'M';
    //std::cout 不需要使用格式符来匹配后面的数据类型，可直接解析
    std::cout << "a = " << a << std::endl;
    std::cout << "b = " << b << std::endl;
    //std::cout可以通过<<链接多个内容
    std::cout << " a = " << a << " b =" << b << " c = " << c << std::endl;

    return 0;
}

    由于C++是默认包含C语言的所有语法的，因此也可以在 C++中使用C的输入和输出

    因为 \ 包含了 \ 无需额外引用

    输出

    #include <iostream>

int main()
{
    int n1 = 10;
    printf("n1 = %d \n" ,n1);   

    return 0;
}

    输入

    需要注意的就是C++当中使用scanf()会触发警告:

    • 改为使用scanf_s()
    • 或者在文件头部添加 #pargma warning(disable:4996) 即禁用这项警告
    #include <iostream>

int main()
{
    int n1 = 0;
    printf("请输入一个整数 \n" ,n1);   
    scanf_s("%d" ,&n1);
    printf("n1 = %d \n" ,n1);

    return 0;
}

    5. 命名空间

    在C语言中如果两个变量或者函数在同一个文件中同名了会触发冲突（不同文件全局变量同名和函数同名也会触发）

    在C++中可以通过使用命名空间来解决这个问题

    5.1 命名空间的创建

    语法：

    namespace 空间名 { 变量、函数 、结构体等等 }

    通过命名空间，可以有同名的变量或者函数，解决了同名的冲突

    #include <iostream>

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

namespace B
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

int main()
{

    return 0;
}

    5.2 访问命名空间中的内容（变量、函数）

    5.2.1 访问方式一

    这里以变量为例

     spacename::variable_name

    变量所属空间的空间名 + 作用域运算符 :: +变量名

    #include <iostream>

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

namespace B
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

int main()
{
    std::cout << "the a in A is :" << A::a << std::endl;//10 
    return 0;
}

    5.2.2 访问方式二

    通过 using namespace spacename 将目标命名空间中的所有内容暴露出来，访问时不用指定命名空间再加上作用域运算符

    #include <iostream>

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

namespace B
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);
}

//使用using namespace 将B中的内容全部暴露出来
using namespace B;

int main()
{
    std::cout << "the a in A is :" << A::a << std::endl;//10 
    //访问B中的内容时无需指定命名空间再加上作用域运算符
    std::cout << "the b in B is :" << b << std::endl;//11

    return 0;
}

    根据此可知使用的输入输出也是有一个 std 的命名空间，因此可以通过同样的方式方便输入输出的使用

    #inlcude <iostream>
using namespace std;

int main()
{
    //直接使用标准输入输出
    cout << "Hello world !" << endl;

    return 0;
}

    5.2.3 访问方式三（不常用）

    通过使用 using 将命名空间中的某一个内容暴露出来

    #include <iostream>
using namespace std;

namespace C
{
    int a = 30;
    int b = 31;
    int cc = 32;
}

//使用using 将C中的某一个变量暴露出来
using C::cc;

int main()
{
    cout << "cc in C is : " << cc << endl; //32

    return 0;
}

    注意：

    • 通过using/using namespace的方式将变量暴露出来，如果暴露出来的变量中有同名变量或者函数，此时依然会触发同名冲突
    #include <iostream>
using namespace std;

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
}

namespace B
{
    int a = 20;
    int b = 21;
    int c = 22;
}

//暴露A
using namespace A;
//暴露B
using namespace B;

int main()
{
    cout << " a = " << a << endl;//会报错，因为A中的a和B中的a冲突了

    return 0;
}

    5.3 命名空间使用的注意事项：

    5.3.1 命名空间只能在全局范围内定义，不能定义在函数或者结构体中

    #include <iostream>

void func1(void);

int main()
{

    return 0;
}

void func1(void)
{
    namespace A
    {
        int a = 1;
    }
}
/*
编译不通过，命名空间不能在函数内定义
*/

    5.3.2 命名空间是开放的，可以随时加入新变量、函数到命名空间中

    原理是同名的命名空间会被编译器直接合并

    因为可以直接合并，命名空间若出现同名变量或者函数等，会触发同名冲突

    #include <iostream>

using namespace std;

//定义了命名空间A
namespace A
{
    int n1 = 15;
}

//定义了命名空间B
namespace B
{
    int n1 = 15;
}

//向A中添加变量
namespace A
{
    int n2 = 25;
}
/*

此时的A实际为：
namespace A
{
    int n1 = 15;
    int n2 = 25;
}

*/

int main()
{
    cout << "n1 = " << A::n1 << endl;
    cout << "n2 = " << A::n2 << endl;

    return 0;
}

    5.3.3 命名空间中的函数声明和定义可以分开，即命名空间中声明，空间外定义

    定义时要保证函数的类型和参数类型一致

    #include <iostream>
using namespace std;

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);//声明在命名空间内
}

int main()
{
    //在主函数中调用
    A::func1();//输出     This is fun1 in A 

    return 0;
}

//通过访问A中的func1来定义
void A::func1(void)
{
    cout << "This is fun1 in A " << endl;
}

    5.3.4 命名空间可以嵌套

    #include <iostream>

namespace D
{
    int d1 = 120;
    namespace E
    {
        char ce = 'F';
        namespace F
        {
            float f1 = 1.23;
        }
    }
}

int main()
{
    //访问也需要通过作用域运算符一级一级调用
    cout << "d1 in D :" << D::d1 << endl;
    cout << "E is in D ,ce in E :" << D::E::ce << endl;
    cout << "F is in E ,E is in D ,f1 is in F :" << D::E::F::f1 << endl;

    return 0;
}

    5.3.5 命名空间可以起别名

    #include <iostream>
using namespace std;

namespace A
{
    int a = 10;
    int b = 11;
    int c = 12;
    void func1(void);//声明在命名空间内
}

//起别名
namespace K = A;

int main()
{
    //访问K也是访问A
    cout << "a in K is :" << K::a << endl;//10

    return 0;
}

    #include <iostream>
using namespace std;

//创建匿名空间
namespace

int main()

    return 0;

    6.2 访问匿名空间中内容

    #include <iostream>
using namespace std;

//创建匿名空间
namespace 
{
    int n1 = 10;

}

int main()
{
    //访问匿名空间中的内容

    return 0;
}

    6.3 匿名空间中变量和函数局部变量以及全局变量之间的关系

    若 ++函数的局部变量，匿名空间中的变量，全局变量都同名++，函数对变量的调用优先级是：

    优先使用局部变量

    若无局部变量，使用匿名空间中的变量

    最后再看全局变量是否有要用的

    局部变量 > 匿名空间 > 全局变量

    #include <iostream>
using namespace std;

//匿名空间
namespace 
{
    int a = 10 ,b = 20;
}

//函数声明
int func1(void);

//全局变量
int a = 110 ,b = 220;

int main()
{
    //调用函数
    cout << "func1's res = " << func1() << endl;// func1's res = 40

    return 0;
}

//函数定义
int func1(void)
{
    //局部变量
    int a = 15 ,b = 25;

    cout << "a = " << a << endl;
    cout << "b = " << b << endl;

    return a+b;
}

    7. 引用

    7.1 引用的基本用法

    引用就是给变量取别名，然后别名和原变量都指向同一块空间，有点像指针

    语法：

    type &new_name = origin_name;

    变量的类型 &别名 = 原变量；

    #include <iostream>
using namespace std;

//引用的基本使用
void reference_basic(void);

int main()
{
    reference_basic();

    return 0;
}

//引用的基本使用
void reference_basic(void)
{
    int a = 10;
    int& b = a;
    cout << "a = " << a << endl;
    cout << "address of a = " << &a << endl;
    cout << "========================" << endl;
    cout << "b = " << b << endl;
    cout << "address of b = " << &b << endl;
    //修改a
    cout << "modified a" << endl;
    a = 11;
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    //修改b
    cout << "modified b" << endl;
    b = 12;
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
}

    7.2 使用引用的注意事项

    7.2.1 引用必须初始化

    不同于指针可以一开始不明确指向的地址，就指向NULL（全局）或者是野指针（局部未初始化），引用在创建的时候必须初始化

    所谓引用的初始化，就是在取别名时，要说明是在给谁取别名

    #include <iostream>

int n1 = 10;
int &n2;//会报错，未初始化指定为谁的别名

int main()
{

    return 0;
}

    7.2.2 引用初始化好后不可更改，即不能重绑定

    不可重绑定的意思是：一个别名只能给一个变量用，如果两个变量有同一个别名，根据更改别名也会更改变量，此时会不知道更改哪一个原始变量

    #include <iostream>
using namespace std;

void reference_re(void);

int main()
{
    reference_re();
    return 0;
}

//引用不可重复绑定
void reference_re(void)
{
    cout << "reference can't rebind" << endl;
    int n1 = 15;
    int& rn1 = n1;
    cout << "n1 = " << n1 << endl;
    cout << "rn1 = " << rn1 << endl;
    int n2 = 20;
    rn1 = n2;//这里并不是将rn1重绑定到n2，而是修改了rn1指向的值，即n1的值也被修改了
    cout << "====================" << endl;
    cout << "n1 = " << n1 << endl;
    cout << "rn1 = " << rn1 << endl;
}

    7.2.3 可通过引用对数组取别名

    type array_name1[size] = {};
type (&new_array_name)[size] = array_name1;

    通过添加小括号提升&符号的优先级，让new_array_name优先和&绑定，若不添加小括号，new_array_name则会和后面的[size]优先绑定，即一个size 长度的 引用类型的数组，但是C++中数组元素不能为引用

    #include <iostream>
using namespace std;

//引用给数组取别名
int array_1[5] = { 1 ,2 ,3 ,4 ,5 };
int(&arr)[5] = array_1;

int main()
{
    //通过别名遍历数组
    for (size_t i = 0; i < 5; i++)
    {
        cout << arr[i] << endl;
    }

    return 0;
}

    7.2.4 引用可以给指针取别名

    #include <iostream>
using namespace std;

void reference_pointer(void);

int main()
{
    reference_pointer();    

    return 0;
}

void reference_pointer(void)
{
    int n1 = 10;
    int *pn1 = &n1;
    //取别名
    int*(&ppn1) = pn1;

    cout << "n1 = " << n1 << endl;
    cout << "n1's address = " << &n1 << endl;
    cout << "pn1 = " << pn1 << endl;
    cout << "ppn1 = " << ppn1 << endl;
}

    7.2.5 引用可以给函数取别名

    取别名方式和数组取别名一致

    return_type func_name (param_list);
return_type (&new_funcname)(param_list) = func_name;

    #include <iostream>
using namespace std;

//函数声明
int func_add(int a ,int b);
//别名
int (&fc_ad)(int a ,int b) = func_add;

int main()
{
    int n1 ,n2;

    cout << "please input two int type num :" ;
    cin >> n1 >> n2;

    //调用别名函数
    cout << "res = " << fc_ad(n1 ,n2) << endl;

    return 0;
}

int func_add(int a ,int b)
{
    return a + b;
}

    7.2.6 函数中的引用

    7.2.6.1 函数参数中的引用

    当函数的参数是引用时，函数内对引用的改变也会改变引用对应的值

    因此可以实现数据交换

    #inlcude <iostream>
using namespace std;

//交换函数
void swap(int &data1 ,int &data2);

int main()
{
    int n1 ,n2;
    cout << "please input two int type num:" ;
    cin >> n1 >> n2;

    int &rn1 = n1;
    int &rn2 = n2;

    cout << "before :" << " n1 = " << n1 << " n2 =" << n2 << endl;
    swap(rn1 ,rn2);
    cout << "after :" << " n1 = " << n1 << " n2 =" << n2 << endl;

    return 0;
}

//交换函数
void swap(int &data1 ,int &data2)
{
    int temp = data1;
    data1 = data2;
    data2 = temp;
}
    7.2.6.2 作为函数返回值

    注意： 不能返回局部变量的引用，一般引用作为函数的返回值，都是返回一些类似于结构体，类这些东西的引用的

    #include <iostream>
using namespace std;

int& add(int a ,int b);

int main()
{
    int num1 = 0, num2 = 0;
    cout << "please input two int type num :" ;
    cin >> num1 >> num2;

    int& res = add(num1 ,num2);
    cout << "res = " << res << endl;
    cout << "&res = " << &res << endl;

    return 0;
}

int& add(int a ,int b)
{
    int sum = a + b;
    cout << "sum = " << sum << endl;
    cout << "&sum = " << &sum << endl;

    return sum;//返回的是sum的别名
}

/*
输出结果：
please input two int type num :10 20
sum = 30
&sum = 00000078FA5EF8B4
res = -858993460
&res = 00000078FA5EF8B4
*/

    说明：sum是函数内的局部变量，res是sum的别名，sum在栈中的空间在函数调用完成后会被释放，因此即使res会指向sum的空间，但是里面的内容已经被释放了，不会是原来的值

    7.2.6.3 作为函数返回值以实现链式编程

    利用更改引用也会更改原值的原理，可以每次让函数返回操作对象的引用，进而实现对操作对象的连续改值等

    #include <iostream>
using namespace std;

//定义结构体（C++中结构体内可以直接定义函数）
struct Stu
{
    int age;
    //以引用为返回值的函数
    Stu& add_age(Stu &stu1 ,int num)
    {
        stu1.age += num;
        cout << "stu1.age = " << stu1.age << endl;
        //返回引用
        return stu1;
    }
};

int main()
{
    //实例化结构体
    Stu stu;
    stu.age = 10;//初始为10
    //调用函数
    stu.add_age(stu ,20).add_age(stu ,30).add_age(stu ,40);
    cout << "final age = " << stu.age << endl;//100

    return 0;
}

    说明：

    • 定义函数时，参数1要求为Stu类型的别名，实际使用的时候直接传入了变量名，为什么没有先创建好一个Stu类型的别名，例如 Stu& rstu = stu;再进行传入呢？ 直接传入和创建好别名再传入本质相同，都是通过操作别名来修改原值，可以直接传入原值的原因是，第一次传入原值stu时编译器会直接将 stu1绑定到stu上，即类似于隐式转换

    7.2.7 常量引用

    即给常量取别名，因为被取别名的是常量，因此别名也不能被修改了，所以需要加上const关键字，类似于常量指针，即所指的内容不能改变，同时因为引用是不能重复绑定的，因此也不能绑定其他的常量

    #include <iostream>
using namespace std;

int main() {
    const int a = 10;
    const int b = 20;

    // 常量引用 ref 绑定到 a
    const int& ref = a;
    cout << "ref = " << ref << endl; // 输出 10

    // 错误！引用一旦绑定，无法重新绑定到 b
    // ref = b; // 这行代码会编译报错，不是因为“常量”，而是引用本身不能换绑

    // 但可以定义新的常量引用绑定到 b
    const int& ref2 = b;
    cout << "ref2 = " << ref2 << endl; // 输出 20

    return 0;
}
